# Sistema de Locadora de Veículos

Projeto acadêmico desenvolvido em Java para simular operações básicas de uma locadora de veículos, aplicando conceitos fundamentais de programação orientada a objetos.

## Funcionalidades

- Simulação de operações de uma locadora de veículos.
- Representação de veículos por meio de classes e objetos.
- Aplicação de herança para organizar e reutilizar código.

## Tecnologias Utilizadas

- Java

## Conceitos Praticados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Herança
- Organização e estruturação de código

## Objetivo do Projeto

Praticar os fundamentos da programação orientada a objetos em Java por meio da modelagem de um sistema de locação de veículos.
